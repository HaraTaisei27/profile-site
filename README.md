# Profile Site

自己紹介用のシンプルなRPG風Webページです。

## URL

https://harataisei27.github.io/profile-site/

## 概要
プロフィール、研究・制作実績、写真、リンクをタブで切り替えて表示するシンプルな自己紹介サイトです。  
RPG風のUIをベースに、リンクボタンやタブ切り替えアニメーションを入れています。

## 使用技術

- HTML
- CSS
- JavaScript

## ファイル構成

- `index.html`: ページの内容
- `style.css`: RPG風の見た目
- `script.js`: タブ切り替え
- `assets/`: 写真や画像
