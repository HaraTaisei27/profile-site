# Profile Site

自己紹介用のシンプルなRPG風Webページです。

## ファイル

- `index.html`: ページの内容
- `style.css`: RPG風の見た目
- `script.js`: タブ切り替え
- `assets/`: 写真や画像

## 編集するところ

まずは `index.html` のプロフィール、写真コメント、リンクを自分用に直してください。

写真を差し替える場合は、画像を `assets/` に入れて、`index.html` の `src="assets/research-desk.png"` を新しいファイル名に変えます。

## 公開するとき

GitHub Pagesに載せる場合は、このフォルダの中身をGitHubリポジトリに置いて、Pagesの公開元を設定します。
